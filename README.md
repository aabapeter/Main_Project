# AI and the Future of Work in India 🇮🇳

### Analyzing Employment Transformation, Occupational Exposure and Emerging Skills

An end-to-end Data Analytics project exploring the relationship between Artificial Intelligence (AI), occupational exposure, employment trends, and workforce transformation in India.

## 📌 Project Overview

Artificial Intelligence and Generative AI are transforming how people work across industries. This project analyzes occupational exposure to AI and employment patterns to understand which types of jobs may experience changes in tasks, workforce demand, and required skills.

Using data analytics and machine learning techniques, the project explores patterns in occupational growth, AI exposure, and potential workforce transformation.

**The goal is to identify relationships and trends, not to assume that AI alone causes employment growth or job losses.**

## 🎯 Objectives

- Analyze AI exposure across different occupations.
- Explore employment growth and decline patterns.
- Investigate the relationship between AI exposure and occupational employment trends.
- Identify occupations that may experience task automation or AI-assisted work.
- Explore emerging skills and workforce transformation.
- Present key findings through data analysis and visualizations.

## 📊 Key Areas of Analysis

### 1. Occupational AI Exposure
Analyze how AI may affect different occupations based on available exposure measures.

### 2. Employment Transformation
Explore occupational employment patterns and identify areas of growth or decline over the available period.

### 3. AI Exposure vs. Employment Trends
Investigate whether occupations with different levels of AI exposure show different employment patterns.

### 4. Automation and Augmentation
Distinguish between tasks that may be automated and tasks where AI may assist workers and improve productivity.

### 5. Emerging Skills
Explore the changing skills and capabilities that may become important as AI adoption increases.

## 🔬 Methodology

1. **Data Collection:** Gather relevant occupational exposure and employment datasets from reliable sources.
2. **Data Cleaning:** Handle missing values, inconsistent categories, duplicate records, and data type issues.
3. **Data Preparation:** Standardize occupation names and map occupational classifications where possible.
4. **Exploratory Data Analysis:** Examine employment patterns, AI exposure levels, and relevant workforce indicators.
5. **Feature Engineering:** Prepare relevant analytical features and prediction-related variables.
6. **Model Evaluation:** Evaluate any machine learning models using appropriate performance metrics.
7. **Visualization:** Present important findings using dashboards, charts, and summary indicators.
8. **Interpretation:** Explain the findings while considering data limitations and avoiding unsupported causal claims.

## 📈 Expected Outcomes

- A clearer understanding of AI exposure across occupations.
- Insights into occupational employment growth and decline.
- Identification of patterns between AI exposure and employment trends.
- An overview of potential workforce transformation and emerging skills.
- An interactive or visual summary of key analytical findings.

## ⚠️ Limitations

- AI exposure does not necessarily mean a job will disappear.
- Employment trends can be influenced by economic conditions, policy, technology adoption, and other factors.
- Different datasets may use different occupational classifications and reference periods.
- Predictions are estimates and depend on data quality, assumptions, and model performance.
- Findings should be interpreted as analytical evidence of patterns and relationships, not proof of causation.

## 🚀 Getting Started

### Prerequisites

Install Python 3 and the libraries required by the project.

```bash
pip install pandas numpy matplotlib seaborn scikit-learn
```

Install any additional dependencies required by the dashboard code.

### Clone the Repository

```bash
git clone https://github.com/aabapeter/Main_Project.git
```

Navigate to the project directory:

```bash
cd Main_Project
```

### Run the Project

Run the relevant Python scripts from the project directory:

```bash
python ai_analysis.py
```

```bash
python evaluate_model.py
```

To launch the dashboard:

```bash
python Tk_DashBoard.py
```

**Note:** The exact execution order and required dependencies should be verified against the Python source files. Run scripts individually as appropriate.
